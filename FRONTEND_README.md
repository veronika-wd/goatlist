# Goatlist — обновлённый интерфейс

Обновлены Blade-представления и стили: публичный список и карточка желания, административные таблицы желаний/категорий/статусов, формы CRUD, вход и регистрация. Добавлено переключение светлой/тёмной темы с сохранением выбора в localStorage.

## Запуск
1. `composer install`
2. Настроить `.env` и базу данных.
3. `php artisan migrate --seed` (если нужны тестовые данные).
4. `npm install` и `npm run dev` (или `npm run build`).
5. `php artisan serve`

## Важно
Бэкенд и маршруты не переписывались. Фильтрация и сортировка публичного списка зависят от реализации `WishController@index`; шаблон отправляет параметры `category_id`, `status_id` и `sort` (newest, oldest, price_asc, price_desc, name). Изображения ожидаются в том формате, который уже использует модель/контроллер проекта.
